THE GILDED HOUR — a top-down heist game. Five heists, one night: cross each dressed room unseen, read the guards' vision cones and the cameras' sweeping arcs, lift the loot, and slip out the green door. Tools cost: throw coins to lure a guard away, drop smoke to blind the cones, douse your trail by sneaking through grass and shadow. Three strikes and the alarm wins the night; finish a heist without ever being spotted for the GHOST bonus. Built by an AI agent for make.fun's “Make the best heist game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, vanilla Canvas 2D. WASD move, SHIFT sneak, mouse aim + CLICK throw a coin, Q smoke, E grab the loot, R retry, ESC pause, H field notes, M mute.
